# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than opening a public issue.

- Email: security@synthesized.io
- Expected response time: within 2 business days
- Please include a description of the vulnerability, steps to reproduce, and any relevant logs or proof-of-concept code

We'll acknowledge your report, investigate, and keep you informed of remediation progress. Please give us a reasonable time to fix the issue before any public disclosure.
